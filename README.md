# Язагрузчик

**Язагрузчик** — бесплатное расширение для Google Chrome, позволяющее скачивать видео с [ЯПлакалъ](https://www.yaplakal.com/) прямо из плеера.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE) ![Chrome Manifest V3](https://img.shields.io/badge/Chrome-Manifest%20V3-blue)

**Автор:** [Antilam](https://antilam.ru/) · [admin@antilam.ru](mailto:admin@antilam.ru)  
**Версия:** 1.1.0

## Возможности

- Кнопка «Скачать» непосредственно в плеере.
- Отдельная кнопка для каждого ролика, даже если на странице несколько видео.
- Выбор доступного качества SD/HD.
- Сохранение прямо в папку загрузок, указанную в настройках Chrome.
- Работа без аккаунта, внешних библиотек и регистрации.

## Установка

1. На странице [Releases](https://github.com/antilamru/yazagruzchik/releases) скачайте архив `yazagruzchik-v1.1.0-extension.zip` (или скачайте исходники этого репозитория).
2. Распакуйте архив в **постоянную папку** на компьютере. Не удаляйте её после установки.
3. Откройте в Chrome `chrome://extensions`.
4. Включите **«Режим разработчика»**.
5. Нажмите **«Загрузить распакованное расширение»** и укажите папку, в которой находится `manifest.json`.
6. Перезагрузите открытую страницу с видео.

Видео сохраняются согласно настройкам `chrome://settings/downloads`. Если установлено «Всегда указывать место для скачивания», браузер покажет окно выбора папки.

**Другие браузеры:** расширение использует Manifest V3 и может быть совместимо с браузерами на Chromium (например, Edge, Brave, Яндекс Браузер). Совместимость с каждым из них отдельно не проверялась; порядок установки и поддержка расширений могут отличаться.

## Использование

Откройте страницу с роликом на ЯПлакалъ. В плеере появится кнопка **«↓ Скачать»**. Нажмите её для загрузки или стрелку рядом, чтобы выбрать качество, если доступно несколько вариантов. Если ссылка на видео ещё не определена, запустите воспроизведение и повторите попытку.

## Ограничения

- Поддерживаются прямые видеофайлы MP4/WebM и другие форматы, указанные в коде. Сборка потоковых HLS/DASH-фрагментов в готовый MP4 не реализована.
- Работа может зависеть от изменений API и верстки плеера.
- Скачивайте только материалы, в отношении которых имеете необходимые права.

## Конфиденциальность и разрешения

Расширение **не отправляет данные на сервер разработчика**, не содержит аналитики и рекламы. Разрешение `downloads` используется для сохранения роликов. Разрешения на доступ к сайтам требуются для обнаружения прямых ссылок на видео в поддерживаемых плеерах; полный список приведён в [`manifest.json`](manifest.json).

## Для разработчиков

Никакой сборки не требуется: исходники JavaScript, HTML и манифест находятся в корне репозитория.

```sh
node tests/test.js
node tests/test-pikabu.js
```

Для браузерного теста `tests/test-browser.py` потребуются Python, Playwright и установленный Chromium. Этот тест не обязателен для установки расширения.
