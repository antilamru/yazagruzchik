ЯЗАГРУЗЧИК — расширение Google Chrome
Разработчик: Antilam (https://antilam.ru/, admin@antilam.ru)

УСТАНОВКА:
1. Распакуйте ZIP в папку, которую не будете удалять.
2. Откройте в Chrome адрес chrome://extensions
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение».
5. Выберите папку yazagruzchik-1.1.0 (в ней лежит manifest.json).
6. Обновите страницу ЯПлакалъ с видео.

КАК ПОЛЬЗОВАТЬСЯ:
Кнопка «↓ Скачать» появится в верхнем правом углу каждого
плеера YapFiles. Она скачивает лучшее доступное качество.
Стрелка ▾ рядом позволяет вручную выбрать качество.

Скачанные видео сохраняются в папку, указанную в настройках Chrome
(chrome://settings/downloads), без дополнительной подпапки.
Если ссылка не найдена, запустите видео и попробуйте ещё раз.
HLS/DASH не поддерживается.
